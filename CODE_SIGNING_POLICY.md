# Code signing policy

The project intends to use free code signing provided by SignPath.io with a
certificate issued to SignPath Foundation, subject to project acceptance.

Until that acceptance and a valid signed artifact exist, releases are clearly
marked unsigned and no automatic updater installs them. GitHub release artifacts
are accompanied by SHA256 checksums and GitHub artifact attestations.

Privacy statement: this program does not transfer user content to networked
systems unless the user explicitly requests or approves the relevant operation.
The Improvement Watcher may retrieve official metadata after opt-in and does not
send prompts, documents, file paths or unique hardware identifiers.

Maintainers, reviewers and signing approvers are listed in `GOVERNANCE.md`.
