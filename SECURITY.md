# Security Policy

## Supported versions

Only the latest stable or release-candidate version receives security fixes.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not include
secrets, personal data or exploit details in a public issue. Include affected
version, reproduction steps, impact and a minimal proof of concept.

We aim to acknowledge a valid report within 7 days. Critical and high findings
block promotion and release until fixed or explicitly mitigated and documented.

## Security properties

ARBELAI Local uses user-scoped installation, explicit approvals, official-source
allowlists, TLS, SHA256 and size verification, archive path validation, atomic
writes, rollback, revocation and local-first privacy. It does not claim to be
free of vulnerabilities.
