# גילוי יכולות מודלים

Gemini CLI לא נמצא ב־PATH ולא נמצאה אינטגרציית Gemini ניתנת להפעלה. לא בוצע Login חדש, לא נקראו Credentials ולא הותקן כלי.

Codex Spark נמצא כמודל זמין בממשק המשימות והופעל למשימת ביקורת תחומה. הוא מתאים לחיפוש מהיר, Fixtures, בדיקות אריזה וסריקות דטרמיניסטיות. הוא אינו משמש להכרעת אבטחה או ארכיטקטורה קריטית.

Claude Code מותקן ומחובר במסלול הרגיל, אך המכסה השבועית חסמה תשובה. מסלול Bare אינו מחובר. התוכנית נשארת `CLAUDE_PLAN_PENDING`.

Codex הראשי ו־ARBELAI זמינים. ARBELAI מוסמך רק לפי קטגוריות שעברו Benchmark, ומידע Restricted או Secret אינו משתחרר לענן.
