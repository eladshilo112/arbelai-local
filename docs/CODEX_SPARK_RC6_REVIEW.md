# ביקורת Codex Spark על RC6

## מסגרת

מודל: Codex Spark. תאריך: 14 באוגוסט 2026. משך: 39.437 שניות. המטרה הייתה ביקורת תחומה של Improvement Watcher, Scheduler ושרשרת האספקה. הקלט הוגבל לתיקיית מוצר נקייה, ללא סודות, מסמכי משתמש או נתונים עסקיים. הפלט נחשב מידע לא מהימן עד אימות Codex הראשי.

## ממצאים שאומתו ותוקנו

1. Revocation נבדק בגילוי אך לא רוענן בכל פעולה מאוחרת. נוסף רענון וחסימה לפני Canary, Benchmark, Compare, Promotion ו־Rollback.
2. Allowlist רישיון ברמת מקור הוגדר אך לא נאכף. השער משתמש כעת ברשימת המקור כאשר קיימת.
3. שערי Claude, חתימת קוד ובדיקה משפטית היו ניתנים בעבר לסימון דרך דגלי שורת פקודה. הדגלים הוסרו והשער דורש ראיות חתומות בהאש מתוך תיקיית Attestations חיצונית.
4. שער ZIP לא אימת בפועל את קובץ ה־SHA256 הסמוך. נוספה חובה לקובץ Checksum והתאמה מלאה לתוכן ה־ZIP.

## ממצא נוסף של Codex בעת אימות הראיות

בבדיקת Metadata אמיתי נמצא כי חיפוש המחרוזת `win` התאים בטעות ל־`darwin`. סיווג הנכסים שונה לסמני מערכת מפורשים, ונוספה בדיקה שמונעת התאמת נכס macOS ל־Windows.

כל התיקונים עברו בדיקות נגזרות. Spark לא הכריע בארכיטקטורה או באבטחה הסופית.
