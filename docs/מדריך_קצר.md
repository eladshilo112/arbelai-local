# ARBELAI Local, מדריך קצר

ב־Windows יש לחלץ את קובץ ה־ZIP וללחוץ פעמיים על `הפעלת ARBELAI.cmd`.

האשף בודק את החומרה ואת נפח האחסון לפני כל הורדה. הוא מציג מקור, רישיון, גודל והתאמת זיכרון ומבקש אישור. ברירת המחדל היא עיבוד מקומי, ללא Telemetry וללא שירות רקע קבוע.

בחר בדיקה בלבד כדי לראות את התוכנית בלי להוריד רכיבים ובלי לערוך את תצורת כלי ה־AI.

בדיקת שיפורים שבועית כבויה. אם בוחרים להפעיל אותה, היא אוספת Metadata רשמי בלבד ומציגה מה נמצא ומה נפסל. הורדת Canary וקידום דורשים אישורים נפרדים.

## English quick start

Extract the ZIP on Windows and double click `הפעלת ARBELAI.cmd`. Choose option 1 for a safe dry run. Downloads and connector changes always require approval.
