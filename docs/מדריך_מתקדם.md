# מדריך מתקדם

## פקודות

בדיקה בלבד:

```text
python portable.py bootstrap --dry-run
```

התקנה אוטומטית אינה מאושרת כברירת מחדל. במסלול אוטומציה מפוקח ניתן להעביר `--approve downloads,integration`.

המשך לאחר הפסקה מתבצע בהפעלה חוזרת. נקודות הבקרה נשמרות תחת `.arbelai-install`. כשל נרשם ב־Failure Memory ללא Secrets.

שחזור:

```text
python portable.py rollback --target PATH --confirm-rollback
```

בדיקת שיפורים היא Metadata בלבד ואינה פעילה ללא הסכמה:

```text
python engine/improvement_watcher.py --root PATH
```

הרצה חד פעמית ללא יצירת Schedule:

```text
python engine/improvement_watcher.py scan --root PATH --session-opt-in
```

ניהול Schedule ברמת משתמש:

```text
python engine/improvement_schedule.py enable --root PATH --approval APPROVE-WEEKLY-METADATA-CHECK
python engine/improvement_schedule.py pause --root PATH
python engine/improvement_schedule.py run-now --root PATH
python engine/improvement_schedule.py disable --root PATH
python engine/improvement_schedule.py remove --root PATH --approval APPROVE-REMOVE-SCHEDULE
```

Canary משתמש באישור התואם למזהה המועמד. Benchmark מופעל על אותו Gold Set, ו־Promotion דורש אישור נוסף. CVE או License במצב Unknown אינם יכולים להגיע לקידום.

בדיקת עדכון אינה מתקינה אוטומטית. בלי Code Signing אמין היא מציעה מידע בלבד.

## English advanced note

The installer is user scoped, resumable and approval gated. The update checker is check only. Promotion requires a canary sandbox, regression benchmark, security gate and user approval.
