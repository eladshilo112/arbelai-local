# מגבלות ידועות

1. ל־Release הנוכחי אין תעודת Code Signing ולכן Windows עשוי להציג אזהרת SmartScreen.
2. macOS ו־Linux תוכננו אך לא נבדקו על מכשיר יעד אמיתי.
3. מדידת Power ו־VRAM אינה זמינה בכל חומרה ולכן הדוח מסמן ערך חסר במקום להעריך.
4. עדכון אוטומטי מושבת עד הקמת חתימה ואימות מפתח ציבורי.
5. תוכנית Productization של Claude Code לא הופקה בסשן הנוכחי עקב מגבלת שימוש שבועית. ראיית הכשל נשמרת, ולכן שער Claude אינו יכול להיחשב עבר.
6. EULA, מדיניות פרטיות ותנאי הפצה דורשים בדיקה משפטית לפני הפצה מסחרית.
7. מקורות רשמיים ללא API יציב, כגון דפי ספקים מסוימים, נשמרים כ־Advisory Only ואינם מועמדים להורדה.
8. CVE Unknown חוסם קידום. לא נעשה ניסיון להסיק היעדר חולשה מהיעדר רשומה.
9. Scheduling ב־macOS וב־Linux תוכנן ונבדק תחבירית, אך לא הופעל על מכשיר יעד.
10. בדיקת Symlink של מערכת הקבצים ו־Junction Abuse דורשת סביבת יעד שבה למשתמש מותר ליצור קישורים. בדיקת Symlink בתוך ZIP כן עברה.
11. Endpoint CVE ללא מיפוי אמין נשאר Unknown וחוסם קידום, גם אם הדבר מונע הצעת מועמד תקין.
