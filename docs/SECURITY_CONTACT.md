# דיווח חולשה ועדכוני אבטחה

לפני הפצה ציבורית יש להגדיר כתובת Security Contact ייעודית. אין לפרסם פרטי חולשה בערוץ ציבורי לפני אישור קבלה ותיאום תיקון.

יעד תגובה מוצע: אישור קבלה בתוך שלושה ימי עסקים, סיווג בתוך שבעה ימים ותיקון דחוף לפי חומרה. רכיב עם חולשה גבוהה או קריטית ייכנס ל־Revocation, יוסר מה־Shortlist והקידום שלו ייחסם.
