# ראיות שימוש בפועל ב־ARBELAI

## ניתוב ופרטיות

ARBELAI Health החזיר Ready, Healthy, תעבורת stdio וללא פורט חיצוני. משימת פרסום חיצוני בסיכון גבוה עם פרטיות Restricted נחסמה ולא נשלחה לענן.

## Context

מנוע ההקשר הופעל עם תקציב של 600 טוקנים ושלוש תוצאות לכל היותר. התוצאה שימשה לביקורת ארכיטקטורה בלבד. נתיבים ותוכן מהמחשב המקורי אינם נכללים במוצר או בדוח ההפצה.

## עיבוד מקומי, Quality Gate ו־Cache

משימת חילוץ מלאכותית נותבה למודל מקומי שהוסמך לקטגוריה. הפלט היה JSON תקין עם `version` ו־`status`. Quality Gate עבר בדיקות Non Empty ו־Valid JSON. זמן הטעינה היה 8.781 שניות וזמן הפעולה הכולל היה 11.844 שניות. בהרצה זהה נוספת התקבל Cache Hit ללא טעינת מודל.

## Benchmark ו־Resource Ledger

אותו Gold Set בעברית ובאנגלית הופעל בפועל על ה־Compute Node הקיים, כאשר הפלט נשמר מחוץ למערכת הפעילה. התקבלו Stability של 1.00, איכות ממוצעת 0.90, TTFT ממוצע 0.902 שניות, קצב ממוצע 6.407 טוקנים לשנייה, Peak RAM של 8,850,231,296 בתים ו־Peak VRAM של 0 במסלול CPU. פעולת המודל המקומי ו־Cache Hit נרשמו ב־Resource Ledger של ARBELAI.

## תוכנית Claude

לא התקבלו החלטות מתוכנית Claude משום שהשירות חסם את ההפעלה עקב מגבלת שימוש. לכן אין לייחס ל־Claude החלטת מוצר כלשהי ושער זה נשאר פתוח.
