# שערי שחרור חיצוניים

PRODUCT_RELEASE_CANDIDATE_READY דורש שלוש ראיות שאינן ניתנות לזיוף באמצעות דגל הפעלה:

1. `CLAUDE_REVIEW.json` עם אישור השלמה, זיהוי מודל ו־SHA256 של הביקורת שנשמרה.
2. `CODE_SIGNING.json` עם אימות חתימה, נתיב Artifact יחסי, טביעת תעודה ו־SHA256 של החבילה החתומה. ב־Windows השער מריץ גם Authenticode ומחייב Status מסוג Valid והתאמת טביעת התעודה.
3. `LEGAL_REVIEW.json` עם אישור בודק מוסמך, תאריך, רשימת מסמכים יחסית ו־SHA256 מחושב של אותם מסמכים.

הראיות נשמרות בתיקייה `release_attestations` ונבדקות מול הקבצים בפועל. אין ליצור קובץ ראיה לפני שהפעולה החיצונית הושלמה באמת. בהיעדר תעודת חתימה, המוצר אינו מתקין עדכון אוטומטית ועלול להציג אזהרת SmartScreen. מסמכי EULA ופרטיות הם טיוטות ואינם ייעוץ משפטי.
