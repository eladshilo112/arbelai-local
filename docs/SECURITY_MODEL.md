# מודל אבטחה

ARBELAI Local מותקן בהיקף המשתמש ופועל בהרשאות המשתמש. אין בקשת Administrator במסלול הרגיל. אין האזנה חיצונית. MCP משתמש ב־stdio. Runtime של מודל נפתח רק על localhost בפורט אקראי, נסגר לאחר הפעולה ונבדק שאין Listener שנותר.

Metadata מרוחק, Model Cards, README, מסמכים ותוכן מאונדקס נחשבים מידע לא מהימן. הם אינם יכולים לשנות מדיניות, להפעיל כלי או לעקוף את Privacy Gate. הורדה מותרת רק דרך HTTPS ומ־Allowlist. ארכיון נבדק נגד Zip Slip. קובץ מודל מאומת באמצעות SHA256 שמגיע מ־Metadata רשמי כאשר הוא זמין.

כתיבה לקובצי תצורה היא אטומית ורק לאחר גיבוי בעל SHA256. אין שינוי Driver, BIOS, Firewall או הגדרת אבטחה.

שער השחרור חוסם ממצא Critical או High ידוע שאינו מטופל. ניסוח בטוח לדוח הוא רק מה שנבדק בפועל, ולא טענה שאין חולשות.
